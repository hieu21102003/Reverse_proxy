    REFERENCE

    API reference

    Endpoints, parameters, and response fields at a glance.

    API VERSION v1
    GET/api/v1/standards/search

    Search the VSQI catalog by standard code or text.

    Query parameters

    qstring · requiredSearch text (2–120 characters).
    pageinteger · optionalPage number from 1 to 1000. Defaults to 1.
    EXAMPLE REQUESTGET /api/v1/standards/search?q=TCVN%209143&page=1
    Example success response
    {
  "data": [{
    "code": "<standard code>",
    "name": "<Vietnamese title>",
    "englishName": "<English title, when available>",
    "year": 2022,
    "status": "Active",
    "detailUrl": "<VSQI detail URL>",
    "source": "VSQI"
  }],
  "pagination": {
    "currentPage": 1,
    "totalPages": 1,
    "totalResults": 1
  },
  "source": "VSQI"
}
    GET/api/v1/standards/:code

    Retrieve the detail record for an exact standard code.

    Path parameter

    codestring · requiredStandard code, URL-encoded (e.g. TCVN 9143:2022).
    EXAMPLE REQUESTGET /api/v1/standards/TCVN%209143%3A2022
    Example success response
    {
  "data": {
    "code": "<standard code>",
    "name": "<Vietnamese title, or null>",
    "englishName": "<English title, or null>",
    "year": null,
    "status": null,
    "issuedDate": null,
    "effectiveDate": null,
    "issuingAgency": null,
    "replacedBy": null,
    "replaces": null,
    "detailUrl": "<VSQI detail URL>",
    "source": "VSQI"
  }
}

    Search result fields

    dataArray of standard records
    paginationcurrentPage, totalPages, totalResults
    sourceUpstream provider identifier
    codeStandard number
    nameVietnamese title
    englishNameEnglish title, when available
    yearPublication year, when available
    statusActive or Withdrawn
    detailUrlVSQI standard page URL

    Detail response fields

    codeStandard number
    nameVietnamese title
    englishNameEnglish title
    yearPublication year
    statusStandard status
    issuedDateIssue date, or null
    effectiveDateEffective date, or null
    issuingAgencyIssuing agency, or null
    replacedByNewer standard, or null
    replacesPrevious standard, or null
    detailUrlVSQI detail page
    sourceVSQI

    Response and error codes

    Successful search responses contain data, pagination, and source. Detail responses contain data with all fields, including null values.

    200 Success400 Invalid input404 Standard not found429 Rate limit exceeded502 Upstream error504 Upstream timeout
    GENERIC ERROR SHAPE{ "error": { "code": "UPSTREAM_TIMEOUT", "message": "VSQI request timed out" }, "source": "VSQI" }
